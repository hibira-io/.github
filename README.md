# hibira-io/.github

Organization-wide defaults for [Hibira](https://hibira.io) repositories on GitHub.

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The public profile shown on https://github.com/hibira-io |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to report bugs and send pull requests |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Community standards |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default issue forms |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Default pull request template |

GitHub uses these files for any repository in the organization that doesn't
have its own copy. A repository can override any of them by adding a file
with the same name.
