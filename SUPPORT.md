# Getting help

| You need help with | Go to |
|---|---|
| Getting started, channels, webhooks, push notifications | [Guides](https://hibira.io/guides) |
| Moving an existing app over from another provider | [Migration guide](https://hibira.io/migrate) |
| Is the service up? | [status.hibira.io](https://status.hibira.io) |
| A bug or feature request for an SDK | An issue in that SDK's repository |
| Your account, apps, billing or the hosted service | **support@hibira.io** |
| Plans, volume pricing or Enterprise | [Contact sales](https://hibira.io/contact-sales) or **sales@hibira.io** |
| A security vulnerability | **security@hibira.io**, see [SECURITY.md](SECURITY.md) |

GitHub issues are for SDK bugs and feature requests. Please don't post
account details, app secrets or personal data in them; email
support@hibira.io for anything that involves your account.

You can write to us in English, 繁體中文, 简体中文, 日本語 and 한국어.
