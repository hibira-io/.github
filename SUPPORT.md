# Getting help

| You need help with | Go to |
|---|---|
| Getting started, channels, webhooks, push notifications | [Guides](https://hikibi.io/guides) |
| Moving an existing app over from another provider | [Migration guide](https://hikibi.io/migrate) |
| Is the service up? | [status.hikibi.io](https://status.hikibi.io) |
| A bug or feature request for an SDK | An issue in that SDK's repository |
| Your account, apps, billing or the hosted service | **support@hikibi.io** |
| Plans, volume pricing or Enterprise | [Contact sales](https://hikibi.io/contact-sales) or **sales@hikibi.io** |
| A security vulnerability | **security@hikibi.io**, see [SECURITY.md](SECURITY.md) |

GitHub issues are for SDK bugs and feature requests. Please don't post
account details, app secrets or personal data in them; email
support@hikibi.io for anything that involves your account.

You can write to us in English, 繁體中文, 简体中文, 日本語 and 한국어.
